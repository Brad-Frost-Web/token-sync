Token Sync bookmarklet

 Preview a room’s tokens on any page, without adding a script to the site. Install and use
  1. Drag this link to your bookmarks bar: Token Sync. Without dragging, open the link’s context menu (right-click, or the menu key with the link focused) and choose to bookmark it.
  2. On the page you want to preview, select the bookmark and type a room code.
  3. To leave, select it again and type off.
 What it can’t do
  • It only reaches the page you select it on. Following a link loads a new page without it, unless that site carries the drop-in script.
  • A site with a strict Content Security Policy can block it. The browser extension is the way around that.
  • Rooms are local to this browser until the relay ships: open the source page in another tab of the same browser.
